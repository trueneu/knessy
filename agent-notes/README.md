# Agent notes

Design notes and findings for agents (and humans) working on knessy.
Start with `CONTEXT.org` in the repository root, which is the short per-project memory.
These files hold the longer write-ups.

- `architecture.md`: how env, views, display pipeline and linked view fit together.
- `shell-and-debug.md`: design of the shell-into-pod and debug-container commands.
- `gotchas.md`: pitfalls found while working on the code.
